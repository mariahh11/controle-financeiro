# Meu Controle Financeiro

Aplicação web para controle de receitas e despesas pessoais. O projeto permite registrar, editar e excluir movimentações financeiras, além de acompanhar o saldo, o total de receitas e o total de despesas.

O projeto foi desenvolvido para praticar e aprimorar conhecimentos em desenvolvimento web, principalmente HTML, CSS e JavaScript.

## Funcionalidades

* Adicionar receitas e despesas
* Editar movimentações
* Excluir movimentações
* Validar os dados informados
* Impedir valores menores ou iguais a zero
* Impedir o cadastro de datas futuras
* Exibir o saldo atual
* Exibir o total de receitas
* Exibir o total de despesas
* Formatar valores em Real (R$)
* Armazenar movimentações no localStorage
* Exibir as movimentações cadastradas na tela

## Tecnologias utilizadas

* HTML5
* CSS3
* JavaScript
* localStorage
